# Test Plan — Chưa verify bằng browser thật

Mọi việc đã implement (typecheck/test/build sạch) nhưng chưa được xác nhận chạy đúng trên Chrome thật — tách khỏi [ROADMAP.md](ROADMAP.md) vì đây là checklist test, không phải trạng thái tính năng. Đọc trước khi định "verify hộ" bất kỳ mục nào ở đây bằng cách đọc code — phần lớn bug thật trong dự án này (xem [CHANGELOG.md](CHANGELOG.md)) chỉ lộ ra khi chạy thật, không lộ khi đọc code.

**Khi verify xong một mục, XOÁ bulletpoint đó khỏi file này** — đừng chuyển nó thành ghi chú "đã test" ở đâu đó khác; ROADMAP.md's write-up của mục đó đã giả định đúng theo thiết kế, chỉ cần dọn cảnh báo ở đây.

**Năng lực agent (cập nhật 2026-07-30):** Playwright (`playwright-core` + `channel:'chrome'`) chạy được Chrome thật. Chrome 150 không còn honor `--load-extension`, nên KHÔNG load được extension thật qua cách đó. Cách vòng đã dùng thành công: CDP `Page.createIsolatedWorld` + `Runtime.evaluate` — đủ trung thực để test hành vi DOM/CSP ở ISOLATED world (đã tái hiện đúng bug `<style>`/CSP của §4.2 design). **Không** thay thế được test cần `chrome.*` API thật (messaging, storage, DNR, offscreen, `chrome.userScripts`) — mọi mục dưới đây vẫn cần user tự test.

## Userscript Platform (§11 ROADMAP)

- **[§11.5] Phase 4 (trục `features/`)** — phần `http-mock` ĐÃ xác nhận (§2.6.2: cả 3 mechanism chạy đúng ở vị trí file mới). Phần `media`/`reader-mode` CHƯA: 2 icon nổi network-sniffer+reader-mode không đè lẫn nhau khi cùng hiện trên 1 trang; Side Panel vẫn list được media sau khi `store.ts` đổi chỗ; network-sniffer's MAIN-world payload vẫn tiêm đúng; reader-mode-converter vẫn chạy đúng ở `features/reader-mode/`.
- **[§11.6] `net.request`** — happy path + từ chối theo `match` ĐÃ xác nhận. Còn lại: response nhị phân lớn (`responseType:'arraybuffer'`) round-trip đúng qua base64 không hỏng byte; timeout 120s thật sự abort request treo; gọi từ dom Module (content-script RPC) chưa thử — mới verify qua đường user-script.
- **[§11.6] `files.save`** — toàn bộ đường chưa chạy qua Chrome thật: `chrome.downloads.download()` với URL `data:` (không phải `blob:`) ghi đúng file ở kích thước gần cap 10MB; `filename` có subfolder tự tạo thư mục con; `conflictAction` mặc định (uniquify) không đổi tên gây bất ngờ; `saveAs:true` mở đúng dialog.
- **[§11.6] `media`** — `list`/`inspect`/`download`/`job` cốt lõi ĐÃ xác nhận. Còn lại: `job()` polling bắt kịp tiến độ khi Side Panel CŨNG đang mở nghe cùng broadcast; snapshot Map mất sau reload extension (không âm thầm giữ state cũ); `control(jobId, ...)` từ script tác động đúng lên job do Side Panel khởi động và ngược lại (chưa thử chiều chéo); download một `variants[]` cụ thể tới nhánh `'done'` (mới xác nhận nhánh `'error'`).
- **[§11.6] `page.eval`** — happy path + `args` + MAIN-world global read-back + throw-rejection ĐÃ xác nhận. Còn lại: trang CSP nghiêm chặn `new Function` trả `{ok:false,error}` đúng thiết kế; timeout 30s thật sự trả lỗi khi `code` treo mà không crash service worker; gọi từ dom Module; hai script cùng gọi `page.eval` trên cùng tab không giẫm lên nhau.
- **[§11.6] Secret Service** — implement xong, 1 bug đã vá qua lượt test đầu (xem CHANGELOG). Manual test: [`docs/examples/test-secrets.js`](examples/test-secrets.js). Đã xác nhận: sửa secret để trống Value giữ nguyên giá trị cũ; xoá `secrets.use` khỏi scopes rồi re-upload như module mới → bị từ chối đúng. Còn lại: header string thường đi cạnh header `secretRef` không bị đụng; host-mismatch giữa `allowedHost` và `net.request`'s `match` độc lập; xoá secret dọn sạch `chrome.storage.local.get(null)`; toggle active/inactive của Secrets panel không ảnh hưởng resolve; gọi từ dom Module.
- **[§11.6] `ai.ask`** — implement xong, chưa verify. Manual test: [`docs/examples/test-ai-ask.js`](examples/test-ai-ask.js). Cần: cài Ollama + pull model nhỏ + `OLLAMA_ORIGINS=*` + upload script + Grant `net.request` cho `http://localhost:11434/*` → happy path trả đúng text; baseUrl ngoài match bị từ chối; messages rỗng bị từ chối trước khi gọi mạng.
- **[§11.6] Trang Help + `synapse-ai-context.md`** — implement xong, chưa verify. Cần: mở popup → Help → trang mở offline, nav nhảy đúng section; bấm Download → file về đúng Downloads, mang đúng version extension đang chạy; màn hình Grant's link "What do these mean?" mở đúng tới mục scopes.
- **[§11] `synapse.bus.on()`, `needs:['net'|'dom']`, `ai.*` throw** — đã dọn ở Phase 2 bằng cách XOÁ khỏi bề mặt, không cần verify lại (không còn tồn tại để test).

## Script Studio (§12 ROADMAP)

- **[§12.1] Vòng đời script** — rename/download/delete ĐÃ xác nhận. Còn lại: upload qua popup thật gán đúng `fileName`, hiện label ngay trước lần chạy đầu; rename sống qua reload TOÀN BỘ extension (không chỉ popup); delete dọn sạch `chrome.storage.local.get(null)` thật (kiểm qua console service worker) VÀ script đã unregister thật; 3 icon lifecycle với label rất dài.
- **[§12.3] Sidebar bước trong Studio** — nhiều bug đã vá qua 2 lượt test (xem CHANGELOG), CHƯA re-verify sau vòng vá thứ 2. Cần: script 3 bước thật trên 1 trang → cả 2 report tới đúng, sidebar hiện đúng thứ tự+trạng thái sau reload Studio; checkbox bypass → reload trang → bước bị bỏ qua thật; bấm dòng sidebar cuộn đúng tới dòng định nghĩa trong Monaco; popup's nút "Steps" biến mất cho script upload; nút Grant hiện đúng cho script `invalid` vì thiếu quyền, hết báo lỗi sau Grant+reload; preview tĩnh khớp đúng `steps` thật sau khi report tới; nút Save/toggle-sidebar đọc được rõ ràng; nút "Reload extension" thật sự giải quyết được ca "Allow User Scripts" (không chỉ đỡ hơn).
- **[§12.4] Template + Clone builtin** — implement xong, đã qua 1 vòng test + 4 bug vá (xem CHANGELOG), CHƯA re-verify sau vòng vá. Cần: Grant hiện ngay sau Save script cần scope, không cần chạy trang thật; hàng nút không bóp méo ở độ rộng popup 340px kể cả khi tất cả cùng hiện; đổi tên inline sống đúng qua Save đầu tiên VÀ qua sửa tên sau khi đã có `moduleId`; cả 3 builtin `active:false` ngay lần đầu mở popup sau build, kể cả profile đã cài từ trước; runtime thật sự dừng theo (không chỉ popup toggle) — vd `network-sniffer`'s `chrome.webRequest` listener không active tới khi user tự bật; 2 tab "My Scripts"/"Builtin" lọc đúng, tổng khớp entry thật.
- **[§12.5] Dry Run "Run once on this tab"** — implement xong, CHƯA test bằng Chrome thật ở bất kỳ vòng nào. Cần: Run trên script ĐANG SỬA (có `moduleId`) → `ctx.api.*` hoạt động ngay bằng grant đã cấp, không hỏi lại; Run trên "New script" chưa Save → mọi `ctx.api.*` bị từ chối "Unknown module" rõ ràng, không throw câm lặng; console panel hiện đúng thứ tự log kèm màu, và ĐỒNG THỜI vẫn thấy ở DevTools thật của tab đích; `pickDryRunTargetTab()` chọn đúng tab vừa rời đi, không nhầm tab Studio/`chrome://`; Run xong không để lại registration nào (`chrome.userScripts.getScripts()` sạch); script 3-bước Dry Run tôn trọng bypass trong sidebar giống production; 2 lượt Run liên tiếp không lẫn log/kết quả (runId lọc đúng).

## Reader Mode / Network Sniffer / Downloader (§1–§10 ROADMAP)

Baseline: engine tải (§8.1–8.5) và Side Panel (§6) đã qua nhiều vòng test thật (đó là cách §6.6–6.7, §8.6–8.11 được phát hiện, xem CHANGELOG) — phần lớn rủi ro runtime ban đầu coi như đã đóng cho luồng chính (HLS pool+AES-128+remux+Pause/Resume/Cancel, header replay §7.1, VanJS render §8.9 — cả hai đã xác nhận). Danh sách dưới là phần CHƯA từng được user xác nhận, hoặc bản vá mới nhất chưa re-test:

- **§9.1** 2 icon nổi Convert/Crawl hiện đúng lúc module active, không đè icon network-sniffer khi cùng hiện; `chrome.sidePanel.open()` qua `synapse:open-side-panel` vẫn giữ user-gesture; Side Panel nhận đúng `synapse:reader-mode-result`/`reader-mode-crawl-progress` dù panel mới mở/còn đang load DOM lúc job bắt đầu; "Download ZIP"/"Open in new tab" dùng đúng blob đã lưu; crawl thật (nhiều trang) chạy hết trong content script không bị Chrome kill khi tab không active.
- **§10.4** Media phát hiện trong iframe cross-origin thật sự hiện lên Side Panel/Dashboard sau khi có `tabUrl` (chưa test site nhúng iframe thật); dời `report-main-world-media`/`report-dom-media` khỏi `run()` không làm rớt detection nào; `notifyTabMediaFound` vẫn ping đúng icon top-frame.
- **§4.2/6.1** Icon nổi/badge: bám đúng vị trí khi cuộn/resize, tự ẩn/gỡ đúng lúc.
- **§5.1** Inspect (auto-inspect §6.3) ra đúng danh sách resolution cho master playlist thật, patch đúng `segmentCount`/`encrypted` cho variant thật.
- **§5.2** Domain/path/query-key filter trên site thật ngoài case đã gặp.
- **§6.8** Click từng resolution link trong Dashboard mở đúng variant URL (không phải variant đầu).
- **§7.2** Magic-bytes probe bắt đúng manifest bị serve sai Content-Type trên site thật; cache theo origin không chặn nhầm URL hợp lệ khác cùng origin.
- **§7.3** — xem `[§7.3-open]` ở ROADMAP's Open Points (đã re-test và KHÔNG khớp kỳ vọng, không còn là "chưa verify" thuần tuý). Còn lại chưa test riêng ở đây: trang có ≥2 player MSE cùng lúc không gán lẫn URL giữa 2 badge; `'play'` capture-phase bắt được trên site chặn `stopPropagation()`; site KHÔNG có `window.Hls` global chưa thử.
- **§10.1** Live capture trên 1 stream live/LL-HLS thật: segment count tăng đúng nhịp; Pause/Resume/Cancel/Stop đúng thiết kế; remux đúng khi dừng (qua Stop lẫn qua `#EXT-X-ENDLIST`); poll cadence theo `targetDurationSec` không dồn cục/bỏ sót; Offscreen Document reload giữa chừng mất file đúng như thiết kế, không lỗi phụ.
- **§2.6.1** `rewriteBodyFile`/`rewriteBodyFileInline` (chiều REQUEST-rewrite) — CHƯA test trên browser thật ở cả 2 mechanism (`main-world` gửi đúng byte nhị phân; `debugger`'s CDP `postData` nhận đúng base64, không bị re-encode hỏng; dọn blob mồ côi đúng khi thay/xoá file). Chiều RESPONSE (`fakeResponseFile`) đã xác nhận qua cả 3 mechanism.
- **§7.4** Một CDN thật trả 401/403 giữa lượt tải, refresh-manifest-rồi-remap thật sự vá được phần còn lại.
- **§7.5** Chưa xác nhận trên site thật có request nào mang tín hiệu path/hostname-prefix mới.
- **§8.2 (Turbo)** Ghi OPFS đồng thời theo offset ra đúng byte; `AbortController`-huỷ fetch dọn sạch; tỉ lệ probe HEAD/Range nhận đúng server hỗ trợ range trên CDN thật.
- **§8.10** `'pausing'`→`'paused'` không bao giờ kẹt dưới tải mạng thật; bấm Download lại ngay sau Cancel luôn là job hoàn toàn mới.
- **§8.12** Cốt lõi ĐÃ xác nhận (reload extension mid-download → Resume → file phát được). Còn lại: `commit()`'s chi phí O(kích thước file) có gây chậm thấy rõ trên stream nhiều GB với interval 20s (mới test vài trăm MB); nhiều vòng crash-resume LIÊN TIẾP trên cùng 1 job chưa thử; `sweepStaleOpfsRuns`'s `keepRunIds` dưới nhiều checkpoint cùng lúc chưa thử.
